# Test data

| File | What | Source |
|---|---|---|
| `qex-budget-ellipsoid.obj` | The integer-grid map (per-corner `vt`) that `QuadExtractor` handed libQEx on the closed-set run ellipsoid_0.4_0.003, fast, 500 quads, 1-ulp replicate 5 (`tools/bench/ab.py --set closed --replicates 5`, master `223e987`). Unguarded libQEx never finishes on it (`try_connect_incomplete_gvertices` loops); `qex_guard_test` checks that the step budget ends it. | Generated by `tools/bench/make_synthetic.py` (ours, GPL-3.0-or-later); written by a temporary dump of `extractWithQex`'s input, not kept in the code |
| `qex-oneway-sculpt-parts.obj` | The map of one island of `sculpt_parts` (sculpt set), quality, 5000 quads, plain input (master `223e987` map, branch head `082f002`). libQEx's `add_face` follows a local edge whose opposite is connected one way only and indexes its grid vertices with a signal value (heap overflow, segfault in 3 of 6 replicates); `qex_guard_test` checks that the guard names it. | Generated by `tools/bench/make_sculpt.py` as of `223e987` (ours; the mesh changed since); dumped as above |
| `qex-faceloop-sculpt-parts.obj` | The same mesh, quality, 15000 quads, plain input. OpenMesh's `delete_face` during libQEx's n-gon merge cuts another face's loop open, and the next face circulation grows a vector without end (6 of 6 replicates killed at 4–12 GB); `qex_guard_test` checks that the face-loop check ends it. | As above |
| `cad-csg-bracket-rot.obj` | The `cad` set's rotated CSG bracket (`cad_csg_bracket_rot`, plain input). At 1000 quads its run with sharp edges lost handles in 12 of 12 runs (fast and quality, 6 replicates, master `2b858a3`); `sharp_edge_fallback_test` checks that the run without them keeps its genus. | Generated by `tools/bench/make_synthetic.py` (ours, GPL-3.0-or-later) |
